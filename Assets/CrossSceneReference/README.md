# Guid Based Reference

Unity package for assigning stable GUIDs to GameObjects and resolving references to those objects across scenes.

## Install via Git URL

Add this package through Unity Package Manager using the package path inside the repository:

```text
https://github.com/Mandariini/guid-based-reference.git?path=/Assets/CrossSceneReference
```

## Contents

- `Runtime`: `GuidComponent`, `GuidManager`, and `GuidReference`
- `Editor`: inspectors and property drawers for GUID-backed references
- `Samples`: sample scenes and scripts showing cross-scene resolution
- `Documentation~`: package documentation

See `Documentation~/guid-based-reference.md` for usage details.
